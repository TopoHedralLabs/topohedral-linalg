1//! # Topohedral-Linalg
2//!
3//! This crate provides a Rust library for small, dense linear algebra. It provides
4//! two matrix types:
5//!
6//! - a runtime-sized `DMatrix`
7//! - a compile-time-sized `SMatrix`
8//!
9//! Both use column-major memory layout and can hold floating-point, integral, and boolean data.
10//! Both have the following features defined for them:
11//!
12//! - Accelerated matrix-matrix and matrix-vector multiplication via BLAS/LAPACK (floating point only)
13//! - Accelerated matrix decompositions and linear system solution via LAPACK (floating point only)
14//! - Lazily evaluated elementwise expressions.
15//! - Matrix subviews
16//! - Lazy element-wise comparisons and boolean masked selection
17//! - Reductions and transformations
18//! - Elementwise functions which mirror those supported for primitive integral and floating-point
19//!   types.
20//!
21//! Matrix storage is column-major. Constructors named `from_row_*` convert row-major input, while
22//! constructors named `from_col_*`, slice conversions, and iterators use column-major order.
23//!
24//! ## Basic use
25//!
26//! ```
27//! use topohedral_linalg::{DMatrix, MatMul, SMatrix, SquareMatrixOps};
28//!
29//! let dynamic = DMatrix::<f64>::from_row_slice(&[1.0, 2.0, 3.0, 4.0], 2, 2);
30//! let fixed = SMatrix::<f64, 2, 2>::identity();
31//! let product = (&dynamic).matmul(&fixed);
32//!
33//! assert_eq!(product.trace(), 5.0);
34//! ```
35//!
36//! ## Views, serialization, and decomposition
37//!
38//! ```
39//! use topohedral_linalg::{DMatrix, SubViewable};
40//!
41//! # fn main() -> Result<(), Box<dyn std::error::Error>> {
42//! let matrix = DMatrix::<f64>::from_row_slice(&[4.0, 1.0, 1.0, 3.0], 2, 2);
43//! let view = matrix.subview_range(0, 1, 0, 0);
44//! assert_eq!(view.iter().copied().collect::<Vec<_>>(), [4.0, 1.0]);
45//!
46//! let encoded = serde_json::to_string(&matrix)?;
47//! let decoded: DMatrix<f64> = serde_json::from_str(&encoded)?;
48//! let cholesky = decoded.cholesky()?;
49//! assert_eq!(cholesky.l[(0, 0)], 2.0);
50//! # Ok(())
51//! # }
52//! ```
53//!
54//! For guides, tutorials, examples and developer documentation, see the
55//! [TopoHedral-Linalg documentation site](https://topohedrallabs.github.io/topohedral-linalg/).
