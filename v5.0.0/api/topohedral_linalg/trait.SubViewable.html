Expand description

Immutable subview constructor methods for any matrix type.

Requires Shape + Index<(usize, usize)> + Sized as supertraits so that MatrixView<'a, Self> is a valid return type. Only subview must be provided; row, rows, col, and cols have default implementations that delegate to it.
